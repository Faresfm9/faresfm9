# FARESFM's Blind Picks

Build me a complete, polished, interactive website for content creation called:

BLIND TOP 5

I am attaching my official channel logo with this prompt. Use the uploaded image as the actual channel logo throughout the website. Do NOT recreate, redraw, modify, or replace the logo.

The website is a Blind Top 5 ranking challenge that I will use while recording videos and livestreams.

==================================================

1. CORE CONCEPT

==================================================

The website has 3 main categories:

1. GAMES

2. ANIME

3. ANIME CHARACTERS

Create a navigation bar at the top that allows me to instantly switch between:

Games | Anime | Anime Characters

Each category has its own predefined pool of items.

The basic gameplay is:

Choose Category

→ Click RANDOM

→ Random item is revealed

→ Rank it from #1 to #5 OR Skip it

→ Click RANDOM again

→ Continue until all 5 ranking positions are filled.

This is a BLIND ranking challenge.

The player must NEVER know which item is coming next.

==================================================

2. MAIN SCREEN / TOP 5 BOARD

==================================================

The main interface should prominently display a TOP 5 ranking board.

Always show five ranking positions:

#1

#2

#3

#4

#5

At the beginning of a round, all five positions are empty.

Each position should have a clean and visually attractive empty placeholder.

When an item is ranked, display its image/poster and name inside the selected ranking position.

Make the rankings large and extremely easy to understand on video.

The #1 position should visually feel like the highest position, but do not make the other positions difficult to see.

Once an item has been placed into a position, that position becomes unavailable for other items.

==================================================

3. RANDOM REVEAL

==================================================

Add a large, prominent RANDOM button.

The text should dynamically match the selected category:

Games:

RANDOM GAME

Anime:

RANDOM ANIME

Anime Characters:

RANDOM CHARACTER

When RANDOM is clicked:

1. Randomly select an unused item from the active category.

2. Do NOT reveal what is coming beforehand.

3. Play a short suspense/reveal animation.

4. Reveal the item's image.

5. Show the item's name clearly.

6. Present buttons to rank it #1, #2, #3, #4, or #5.

7. Also present a SKIP button.

Make the reveal exciting and satisfying for YouTube/TikTok/stream content.

The reveal animation should be visually impressive but SHORT.

I will use this repeatedly during videos, so avoid slow animations.

==================================================

4. RANDOMIZATION RULES

==================================================

Random selection must be genuinely random.

An item cannot naturally appear twice during the same round.

Once an item has been revealed, remove it from the available random pool for that round.

Do not show upcoming items anywhere in the interface.

Do not preload upcoming item names visually where the player or viewers could see them.

The blind aspect of the game is extremely important.

==================================================

5. RANKING SYSTEM

==================================================

After revealing an item, allow the player to choose:

#1

#2

#3

#4

#5

Only EMPTY ranking positions should be selectable.

If #2 already contains an item, for example, #2 should be visibly locked/unavailable when ranking the next item.

When a ranking position is selected:

- Animate the item moving into the selected position.

- Lock it into that ranking.

- Update the Top 5 board immediately.

- Return to the state where the player can click RANDOM again.

Once all five positions are filled:

Stop allowing additional random selections.

Display an exciting:

TOP 5 COMPLETE

state.

Show the completed Top 5 clearly.

==================================================

6. SKIP SYSTEM

==================================================

Every revealed Game, Anime, or Anime Character must have a SKIP option.

If the player does not want to rank the current item, they can press:

SKIP

When SKIP is pressed:

- Do not place the item anywhere in the Top 5.

- Mark that item as used for the current round.

- Do not allow that skipped item to appear again during the same round.

- Keep all ranking positions unchanged.

- Play a quick smooth skip animation.

- Return to the RANDOM state so another item can be generated.

SKIP should NOT fill a ranking position.

Allow the player to use SKIP whenever they want.

Do not impose a fixed skip limit.

==================================================

7. RESET / NEW ROUND

==================================================

Add a NEW ROUND / RESET button.

It should be visible but not more visually dominant than the RANDOM button.

When activated:

- Clear all Top 5 positions.

- Clear all used/skipped item history.

- Restore the full pool for the currently selected category.

- Start a completely fresh round.

If appropriate, show a small confirmation before resetting an active round to prevent accidental resets.

==================================================

8. CATEGORY SWITCHING

==================================================

The website contains:

GAMES

ANIME

ANIME CHARACTERS

Switching categories should feel smooth.

Each category should use the same Blind Top 5 gameplay system but its own item database.

Prefer preserving the current round of each category when switching tabs.

For example:

If I rank 3 Games, switch to Anime, and later return to Games, my current Games Top 5 progress should still be there.

NEW ROUND should reset only the currently active category unless a global reset is explicitly chosen.
